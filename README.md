# Project 25/26 Seravo-0 / Sapor

Structure-only skeleton of the archive layout. No personal content is included.

```
archive/
  <session-id>.md              # per-session notes/summary
  transcripts/
    <session-id>.jsonl         # raw transcript for the same session
```

Each session has one `.md` and one matching `.jsonl` sharing the same `<session-id>`.
Real content is git-ignored; only the folder layout is tracked.
