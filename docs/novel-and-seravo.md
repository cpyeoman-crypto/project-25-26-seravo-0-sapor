# The novel and Seravo-0

This note avoids story details on purpose. It lists connections worth exploring together.

## What is known
- The novel is a long-running sci-fi/fantasy project that is being revived with the help of a local LLM.
- It has its own machine, kept apart from the security network, with a creative model and a writing workspace.
- That machine is also the high-availability backup for Seravo-0, so the creative and protective sides depend on each other.
- The archivist role keeps the novel's versions and research notes alongside the network history.

## Questions to explore
- Should Seravo-0 and the creative model share a memory store, or stay fully separate?
- Could the network's own milestones (new client online, audit passed) become in-world events?
- Should the novel's world-building notes live in this repo, or only the structure around them?
- What should the creative model be allowed to see of the network, if anything?
- Is a franchise-style structure (prequel, main series, later parts) worth mirroring in how the archive is organised?
