# Roadmap: clients to come

- **New fleet nodes:** join automatically through pre-approved, tagged keys, using the scout template.
- **Burst compute nodes:** cold spares that wake over the network for large jobs.
- **Controller migration:** the network controller moves onto the edge enforcer, which also gains audible alarms.
- **Autonomous fleet behaviour:** clients update themselves, send frequent thermal telemetry, and restart their own tunnels when they drop.
- **Credential vault:** a vault for recovering systems and reissuing client identities.
- **Bigger local models:** more RAM and fast storage so the orchestrator can run larger LLMs.
